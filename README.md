# Superstore Sales Analysis

This project analyzes sales data using Python and Power BI.

## Tools Used
- Python
- Pandas
- Power BI

## Steps Performed
1. Loaded dataset using pandas
2. Checked duplicates and cleaned data
3. Converted date columns
4. Built interactive dashboard in Power BI

## Dashboard Insights
- Total Sales
- Sales by Category
- Sales by Region
- Top 10 Products by Sales
- Monthly Sales Trend
